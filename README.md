# LeetCode 12 - Integer to Roman

## Problem Number
LeetCode 12

## Problem Title
Integer to Roman

## Difficulty
Medium

## Problem Description

Roman numerals are represented using seven different symbols:

| Symbol | Value |
|--------|-------|
| I | 1 |
| V | 5 |
| X | 10 |
| L | 50 |
| C | 100 |
| D | 500 |
| M | 1000 |

Given an integer, convert it into its Roman numeral representation.

Roman numerals use the following subtractive combinations:

- IV = 4
- IX = 9
- XL = 40
- XC = 90
- CD = 400
- CM = 900

The input number is between 1 and 3999.
