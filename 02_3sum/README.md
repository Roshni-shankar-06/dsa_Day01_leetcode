# LeetCode 15 - 3Sum

## Problem Number

LeetCode 15

## Problem Title

3Sum

## Difficulty

Medium

---

## Problem Description

Given an integer array `nums`, return all the triplets:

`[nums[i], nums[j], nums[k]]`

such that:

- `i != j`
- `i != k`
- `j != k`
- `nums[i] + nums[j] + nums[k] == 0`

The solution must not contain duplicate triplets.
